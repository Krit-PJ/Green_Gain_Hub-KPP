# GHG Calculation Engine v1.0 — การเผาวัสดุเหลือใช้ทางการเกษตร

โค้ด: `apps-script/Ghg.gs` · ทดสอบ: `tests/residue-ghg.test.js` และปุ่ม "ทดสอบสูตร (Validation Test)" ในหน้า `admin.html` > ตั้งค่า > ราคาและค่าคำนวณ

> 2.2.0: หน้าเว็บและรายงานแสดงหน่วยเป็นภาษาไทย **ตันคาร์บอนไดออกไซด์เทียบเท่า** (tCO2e), กิโลกรัม/กรัมคาร์บอนไดออกไซด์เทียบเท่า (kgCO2e, gCO2e) สูตรและค่าไม่เปลี่ยน เอกสารนี้ใช้สัญลักษณ์เดิมเพื่ออ้างอิงกับ IPCC

ในระบบนี้ผลลัพธ์รายงานเป็น **"ปริมาณ GHG ที่ลดได้ (ประมาณการ)"** หมายถึง CH₄ + N₂O ที่จะเกิดขึ้นหากเผาวัสดุเหลือใช้ทางการเกษตรในพื้นที่ที่จัดการแทนการเผา (ไถกลบ อัดฟางก้อน อัดใบอ้อย ทำปุ๋ยหมัก เพาะเห็ด ฯลฯ)

## 1. Mathematical Model Specification

สมการพื้นฐาน IPCC 2006 Vol.4 Ch.2 Equation 2.27: `L_fire = A × MB × Cf × Gef × 10⁻³` แปลงเป็น CO₂e ด้วย GWP ของก๊าซแต่ละชนิด

| สมการ | สูตร | หน่วย |
| --- | --- | --- |
| Eq.1 Total Biomass Consumed | `Btotal_i = A_i × Bburned_i` | kg dry matter burnt |
| Eq.2 Methane | `CH4_tonnes_i = Btotal_i × EF_CH4 / 1,000,000`, `CH4_CO2e_i = CH4_tonnes_i × GWP_CH4` | t CH₄, tCO₂e |
| Eq.3 Nitrous oxide | `N2O_tonnes_i = Btotal_i × EF_N2O / 1,000,000`, `N2O_CO2e_i = N2O_tonnes_i × GWP_N2O` | t N₂O, tCO₂e |
| Eq.4 L_fire per crop | `L_fire_i = CH4_CO2e_i + N2O_CO2e_i = A_i × Bburned_i × 94.15 / 1,000,000` | tCO₂e |
| Eq.5 Standard | `L_fire_i = A_i × Bburned_i × 0.00009415` | tCO₂e |
| Eq.6 Custom | `L_fire_i = A_i × MB_i × Cf_i × 0.00009415` (Cf 0.80 → `A_i × MB_i × 0.00007532`) | tCO₂e |
| Eq.7 ต่อไร่ | `GHG_per_Rai_i = L_fire_i × 1,000 / A_i` (A_i = 0 → แสดง N/A ไม่หารด้วยศูนย์) | kgCO₂e/ไร่ |
| ผลรวม | `GHG_total = ΣCH4_CO2e_i + ΣN2O_CO2e_i` (ไม่รวมตัน CH₄ กับตัน N₂O โดยตรง) | tCO₂e |

`EF_CO2e = (2.7 × 28) + (0.07 × 265) = 94.15 gCO₂e/kg dry matter burnt` คำนวณจากค่าที่บันทึกในชีต `ghg_params` ทุกครั้ง ไม่ได้ฝังตัวเลขไว้ในสูตร

## 3. Calculation Logic

- **Mode A — Standard:** `Bburned = Biomass consumed (Table 2.4)` **ไม่คูณ Cf ซ้ำ** และแสดง "Biomass Before Burning = N/A"
- **Mode B — Custom:** `Bburned = MB × Cf` โดย MB เป็นน้ำหนักแห้ง ถ้ามีเฉพาะน้ำหนักสด: `MB = Fresh × DryMatterFraction` (ต้องระบุ DMF 0–1) และต้องระบุแหล่งอ้างอิง/วิธีวัด → Data Status = Measured
- **DEFAULT_MODE = residue** (เลือกได้): ใช้ `MB = วัสดุเหลือใช้ทางการเกษตรต่อไร่ × 1,000` (สกว.) `× Cf` เป็นค่าเริ่มต้นแทน Table 2.4
- **Validation (Test Case 5):** พื้นที่/ชีวมวลติดลบ, Cf นอกช่วง 0–1, ข้อมูลไม่ครบ, ไม่มีแหล่งอ้างอิงใน Custom และพืชไม่มีค่ามาตรฐานแต่เลือก Standard → แจ้งข้อผิดพลาดและไม่แสดงผลรวม
- ปีงบประมาณ = 1 ต.ค. – 30 ก.ย. (ต.ค. 2569 → ปีงบ 2570)

ขอบเขต: เป็นการลดแบบขั้นต้น (gross) ในแปลงเท่านั้น ไม่นับ CO₂ ชีวภาพในบัญชีสุทธิ (แต่ไม่ได้หมายความว่าการเผาไม่ปล่อย CO₂) ไม่รวม CH₄ ที่อาจเพิ่มจากการไถกลบฟางในนาน้ำขัง ปุ๋ย การขนส่ง เครื่องจักร หรือการใช้วัสดุเหลือใช้ทางการเกษตรนอกแปลง (เช่น ฟางอัดก้อนที่นำไปเผาในโรงไฟฟ้า) พื้นที่มาจากการบันทึกของเจ้าหน้าที่ ไม่ใช้จุดความร้อนหรือคะแนนความเสี่ยงแทน และไม่ใช่คาร์บอนเครดิตที่ได้รับการรับรอง
