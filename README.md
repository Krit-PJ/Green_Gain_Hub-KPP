# Green Gain Hub 1.7.0

## ใหม่ในรุ่น 1.7.0

- **ระบบรายงาน (`admin.html` > รายงาน):** เฉพาะ Super Admin และ Admin เลือกส่วนรายงานได้ 5 หมวด
  - ก. สถานการณ์การเพาะปลูก (ภาพรวมจังหวัด, รายเดือน, รายอำเภอ, รายตำบล) เลือกชนิดพืชและ "ข้อมูล ณ สิ้นเดือน"
  - ข. รายงานอำเภอ KPP Smart Agri-Materials (สถานะส่งรายงาน, R29–R31, ยอดสะสมรายครั้ง)
  - ค. ตลาดเศษวัสดุ (สรุปรายอำเภอ, ตามชนิดวัสดุ; รายการแปลงและจุดรับซื้อที่มีชื่อ/เบอร์โทร **เฉพาะ Super Admin** ปิดบังเบอร์เป็นค่าเริ่มต้น)
  - ง. สถิติผู้เข้าชม (รายเดือน, รายวัน 90 วัน)
  - จ. ประวัติการนำเข้า และบันทึกการใช้งานผู้ดูแล (เฉพาะ Super Admin)
  - ส่งออก: **พิมพ์/PDF** (A4 แนวตั้ง/แนวนอน), **Excel (.xlsx)** แยกชีตตามส่วน, **CSV** (UTF-8 เปิดใน Excel ภาษาไทยได้) ทุกการดูและส่งออกถูกบันทึกใน `admin_log`
- **ตัวนับผู้เข้าชมท้ายหน้า:** "วันนี้ · เดือนนี้ · ทั้งหมด" นับ 1 ครั้งต่อ session ของเบราว์เซอร์ เก็บรายวันในชีต `visit_stats` และยอดรวมต่อจากค่า `visit_count` เดิมในชีต `Config`
- Apps Script เพิ่มไฟล์ `Counter.gs`, `Reports.gs`

## รุ่น 1.6.0

- **ข้อมูลการเพาะปลูก:** ผู้ดูแลนำเข้ารายงานจากระบบฐานข้อมูลทะเบียนเกษตรกรกลาง (.xlsx/.csv) แยกตามเดือนที่คาดว่าจะเก็บเกี่ยว พืชละ 1 ไฟล์ ต้องเลือกชนิดพืชก่อนนำเข้า
  - พื้นที่ปลูก = ผลรวมทุกเดือน, เก็บเกี่ยวรายเดือน = ค่าของแต่ละเดือน, คงเหลือ = พื้นที่ปลูก − เก็บเกี่ยวสะสมถึงสิ้นเดือนที่ผ่านมา
  - นำเข้าพืชและปีการผลิตเดิมซ้ำ = แทนที่ชุดเดิม (ตัวเลขเพิ่มหรือลดตามไฟล์ล่าสุด ไม่นับซ้ำ) เก็บประวัติทุกครั้ง
  - ตรวจผลรวมตำบล = อำเภอ = จังหวัด ทุกเดือนก่อนบันทึก รองรับหลายชนิดพืช (ข้าวนาปี ข้าวนาปรัง อ้อยโรงงาน ข้าวโพดเลี้ยงสัตว์ มันสำปะหลัง และเพิ่มเองได้)
- **ระบบผู้ดูแล (`admin.html`):** Super Admin และ Admin เข้าด้วยชื่อผู้ใช้และรหัสผ่าน (hash + salt), ล็อก 15 นาทีเมื่อใส่ผิด 5 ครั้ง, เซสชัน 2 ชั่วโมง, บันทึกการใช้งานทุกครั้ง
  - Admin: นำเข้า/ลบชุดข้อมูล, จัดการชนิดพืช, อัปเดตหน้าแรก
  - Super Admin: + การเชื่อมต่อ API (Smart Agri URL/API Key แบบเขียนอย่างเดียว), ผู้ดูแลระบบ, บันทึกการใช้งาน
- **หน้าแรกแบ่งแท็บ:** ภาพรวม | การเพาะปลูก | รายงานอำเภอ | ตลาดเศษวัสดุ แต่ละแท็บมีตัวเลขสรุป ตัวชี้วัดบนแผนที่ และตารางของตัวเอง
  - แท็บการเพาะปลูก: เลือกพืช, เลือก "ข้อมูล ณ สิ้นเดือน", กราฟเก็บเกี่ยวรายเดือน, กราฟเก็บเกี่ยวแล้ว/คงเหลือ, ตารางอำเภอ และรายตำบลเมื่อเลือกอำเภอ
- Apps Script แยกไฟล์: `Code.gs`, `Districts.gs`, `Admin.gs`, `Crops.gs` (ชีตเดิมไม่เปลี่ยน เพิ่มชีตใหม่ 5 ชีต)

- หน้าแรกแสดงตัวเลขสรุป, แผนที่ระบายสีรายอำเภอ (11 อำเภอ), ปฏิทินเก็บเกี่ยว, สรุปตามชนิดเศษวัสดุ และตารางรายอำเภอ พร้อมกล่องเข้าสู่ระบบด้านข้าง (มือถือแสดงกล่องเข้าสู่ระบบก่อน)

## ประวัติรุ่น 1.4.1

รุ่นนี้เพิ่มการจับคู่ชนิดพืชกับชนิดเศษวัสดุอัตโนมัติ และแก้การตรวจ Backend รุ่นใหม่กว่าให้ผ่านอย่างถูกต้อง โดยคงโครงสร้าง Google Sheet และระบบเดิม

### สิ่งที่เปลี่ยน

- Frontend ตรวจว่า Backend ไม่ต่ำกว่า `1.3.1` แทนการบังคับให้เลขเวอร์ชันตรงกันทุกตัว
- `1.3.1`, `1.4.0` และ `1.4.1` จึงไม่ถูกปฏิเสธเพียงเพราะเลขเวอร์ชันไม่ตรงกัน แต่ยังตรวจโครงสร้าง response ที่จำเป็น
- เมื่อเลือก `ข้าวนาปี` หรือ `ข้าวนาปรัง` ระบบกำหนดชนิดเศษวัสดุเป็น `ฟางข้าว`
- เมื่อเลือก `อ้อยโรงงาน` ระบบกำหนดชนิดเศษวัสดุเป็น `ใบอ้อย`
- เมื่อเลือก `มันสำปะหลัง` ระบบกำหนดชนิดเศษวัสดุเป็น `เหง้ามันสำปะหลัง`
- เมื่อเลือก `อื่นๆ` ผู้ใช้ระบุชนิดเศษวัสดุอื่นได้
- Backend บังคับการจับคู่ซ้ำอีกชั้น ป้องกัน Frontend เก่าหรือคำขอที่แก้ไขค่าบันทึกคู่พืช–เศษวัสดุไม่สอดคล้องกัน
- `Phone` และ `Owner_Telephone` บันทึกเป็นข้อความเพื่อรักษาเลข `0` ด้านหน้า
- ข้อมูลเก่าที่โทรศัพท์เหลือ 9 หลักจากการถูกแปลงเป็นตัวเลข จะถูกเติม `0` ขณะเข้าสู่ระบบ เปรียบเทียบเจ้าของ และแสดงผล
- `Plant_Date` และ `Havest_Date` แสดงในชีตเป็น `yyyy-mm-dd`
- Backend อ่านข้อมูลวันที่เดิมได้ทั้ง `yyyy-mm-dd` และ `d/m/yyyy` รวมถึงปี พ.ศ.
- `setupSystem()` แปลงเฉพาะเบอร์/วันที่เดิมที่ตรวจสอบรูปแบบได้แน่นอน และปล่อยค่าที่กำกวมไว้ตามเดิม
- นำช่อง “ต้องการรับซื้อภายในกี่วันหลังเก็บเกี่ยว” ออกจากแบบฟอร์มผู้รับซื้อ
- คอลัมน์ `buyers!Q` ยังคงอยู่เพื่อไม่เปลี่ยน schema แต่ระบบไม่ใช้ค่านี้กรองหรือแสดงผล และการบันทึกใหม่ใช้ค่าเป็นกลาง `ALL`
- ป้ายพิกัดเกษตรกรเป็น “พิกัดแปลง”
- ป้ายพิกัดผู้รับซื้อเป็น “พิกัดสถานที่รับซื้อ”
- เมื่อเกษตรกรเปิด “แผนที่ & คู่ค้า” ระบบแสดงทุกแปลงของบัญชีที่มีพิกัด พร้อมผู้รับซื้อ `Active`
- ผู้รับซื้อยังเห็นเฉพาะเกษตรกร `Open` ตามตัวกรองเดิม
- ปุ่มโทรและนำทางยังสร้างเฉพาะรายการคู่ค้าฝั่งตรงข้าม

### ความเป็นส่วนตัวของแผนที่

- เกษตรกรได้รับข้อมูลผู้รับซื้อและแปลงของตนเองเท่านั้น
- เกษตรกรไม่ได้รับข้อมูลแปลงของเกษตรกรรายอื่น
- ผู้รับซื้อได้รับเฉพาะข้อมูลแปลงเกษตรกร ไม่ได้รับข้อมูลผู้รับซื้อรายอื่น
- การรวมแปลงของบัญชีใช้ `Owner_Telephone` และใช้ `Phone` เป็นคีย์สำรองสำหรับข้อมูลเก่า
