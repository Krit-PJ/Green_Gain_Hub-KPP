# Green Gain Hub 4.2.1 — ศูนย์กลางเชื่อมโยงการซื้อ-ขายวัสดุเหลือใช้ทางการเกษตร ทุกจังหวัด

## ใหม่ในรุ่น 4.2.1 (การ์ดวัสดุแสดงเป็นไร่ · ปรับหน้าจอมือถือ — 28 พ.ย. 2569 · เฉพาะหน้าเว็บ ไม่ต้อง Deploy Apps Script)
- การ์ดวัสดุในตลาด: "ประกาศขาย" แสดงพื้นที่ (ไร่) ที่เกษตรกรแจ้ง แทนตันประมาณการ บรรทัดอื่นคงเดิม · ทุกการ์ดรูปแบบเดียวกัน · รายการบนแผนที่/รายการไม่แสดงตันประมาณการ
- ตันประมาณการคงอยู่ที่ช่อง "ประมาณการชีวมวล" ตารางสรุปรายอำเภอ และรายงานพิมพ์ของเจ้าหน้าที่ · เลือกการ์ดแล้วช่องสรุป ตาราง และแผนที่เปลี่ยนตามวัสดุเดียวกัน (ตัวเลขไร่ตรงกันทุกส่วน)
- มือถือ: กล่องตลาดไม่ล้นจอ (ตัวเลือกจังหวัดเคยดันความกว้าง) · ตารางรายอำเภอพอดีจอ 360 px

## ใหม่ในรุ่น 4.2.0 (การ์ดผู้ใช้งาน · บันทึกข้อมูลเพาะปลูก · แดชบอร์ดเจ้าหน้าที่ — 28 พ.ย. 2569)
- **ผู้ใช้งานปัจจุบัน** รวมข้อมูลผู้ใช้งานเป็นการ์ดย่อย (ดู/แก้ไข แล้วบันทึกได้) แสดงจังหวัดของผู้ใช้ · เบอร์เข้าสู่ระบบแก้ไม่ได้ แก้ได้เฉพาะชื่อ เบอร์ติดต่อ และจังหวัด (`updateProfileServer`)
- แท็บ **บันทึกข้อมูลเพาะปลูก / แผนที่ & คู่ค้า** อยู่ในการ์ดผู้ใช้งาน ไม่เปลืองพื้นที่ (ผู้รับซื้อ: **บันทึกข้อมูลการรับซื้อ**)
- หน้าบันทึก: ซ้าย = แผนที่เดียวแสดงทุกแปลง (หมุดมีหมายเลข) · ขวา = ปุ่ม **แปลงเพาะปลูกที่ 1, 2, …** (เฉพาะที่บันทึกแล้ว) + ปุ่มเพิ่มแปลงใหม่ · ส่วน "ชนิดพืช" แทน "พืชและวัสดุเหลือใช้" (ช่องวัสดุแสดงเฉพาะพืช "อื่นๆ")
- **เจ้าหน้าที่**: Super Admin ตั้งรัศมี "รวมคู่ค้าต่างจังหวัด" ได้ 10–100 กม. (ค่าเริ่มต้น 50) ที่ ตั้งค่าตลาด
- แดชบอร์ดเจ้าหน้าที่ใหม่ (ปรับจากคลิปตัวอย่าง แต่คงโทนเขียว GGH และอ่านง่ายสำหรับผู้สูงอายุ): เมนูจัดกลุ่ม แดชบอร์ด/ข้อมูล/ระบบ · คำทักทายตามช่วงเวลา + วันที่ไทย · KPI มีไอคอนและป้าย ข้อมูลจริง/ประมาณการ · กราฟพื้นที่ใกล้เก็บเกี่ยวรายเดือน และกราฟวัสดุเหลือใช้ทางการเกษตร (แตะ/ชี้เพื่อดูตัวเลข) · ปุ่มกรองตามสถานะในหน้ารายการ
- Apps Script: Code.gs + Admin.gs (เวอร์ชัน 24)

## ใหม่ในรุ่น 4.1.0 (หน้าเกษตรกร/ผู้รับซื้อ · รัศมี 50 กม. · สีอ่านง่าย — 25 พ.ย. 2569)

- **หน้าบันทึกข้อมูล:** แต่ละการ์ดแปลง/จุดรับซื้อ แผนที่ตำแหน่งอยู่ซ้าย ข้อมูลอยู่ขวา (มือถือ: แผนที่ก่อน แล้วข้อมูล) แผนที่สูงขึ้น ปักหมุดง่ายขึ้น
- **หน้าแผนที่ & คู่ค้า:** แผนที่ซ้าย รายชื่อคู่ค้าขวาแบบหน้าแรก การ์ดคู่ค้าแบบใหม่ (ปุ่มโทร/นำทางใหญ่ ระยะทางเด่น)
- **สวิตช์ "รวมคู่ค้าต่างจังหวัดในรัศมี 50 กม.":** นับจากหมุดแปลงหรือจุดรับซื้อของผู้ใช้เอง (ไม่ใช้ GPS โทรศัพท์) รายการจากจังหวัดอื่นมีป้ายชื่อจังหวัด ระบบจำค่าที่เลือก ปิดเป็นค่าเริ่มต้น — `getMatchingDataServer({nearKm: 50})`
- **สีและตัวอักษรสำหรับผู้สูงอายุ:** ตัวอักษร 18px ปุ่ม/ช่องกรอกสูง ≥ 48–52px ตัวอักษรตัดกับพื้นอย่างน้อย 4.5:1 เขียว = ผู้ขาย น้ำตาลทอง = ผู้รับซื้อ แดง = ลบเท่านั้น
- Apps Script: `Code.gs` (`APP_VERSION` 4.1.0)

## ใหม่ในรุ่น 4.0.0 (เจ้าหน้าที่ของระบบเอง · รายงาน — 25 พ.ย. 2569)

- **ยกเลิกการเชื่อมโยง SSO** กับระบบอื่น (ลบ `Sso.gs`) · เจ้าหน้าที่ของ Green Gain Hub มี 2 บทบาท: **Super Admin** (ทุกจังหวัด) และ **Admin** (เฉพาะจังหวัดที่ลงทะเบียน) เข้าสู่ระบบด้วยชื่อผู้ใช้ + รหัสผ่าน (เก็บแบบแฮช ผิด 5 ครั้งล็อก 15 นาที)
- เมนู **"เจ้าหน้าที่"** มุมขวาบนของหน้าแรก → `admin.html` (เข้าสู่ระบบ / สมัคร Admin จังหวัด — รอ Super Admin อนุมัติ)
- **Admin:** ภาพรวมจังหวัด · ผู้ใช้ (แก้ไข/ลบ) · แปลงประกาศขายและจุดรับซื้อ (ดูเบอร์และพิกัด เปลี่ยนสถานะ ซ่อน/ลบ) · รายงาน — เฉพาะจังหวัดของตน ทุกการดูข้อมูลส่วนบุคคลและการแก้ไขบันทึกใน `ggh_admin_log`
- **Super Admin:** ทุกอย่างของ Admin ทุกจังหวัด + อนุมัติ/จัดการเจ้าหน้าที่ ตั้งรหัสผ่านใหม่ ตั้งค่าตลาด (จำนวนวันแสดงแปลงหลังเก็บเกี่ยว — ย้ายมาจาก ABM; `abm_config` เหลืออ่านอย่างเดียว) ประวัติการใช้งาน
- **รายงาน + พิมพ์ A4 แนวนอนแบบ Agri-Risk Map Burning:** หัวรายงาน (ขอบเขต ช่วงข้อมูล ข้อมูลล่าสุด วันที่พิมพ์) · แผนที่จังหวัดแรเงาตามพื้นที่ประกาศขาย + คำอธิบาย + ตัวเลขสำคัญ | ตารางครบทุกอำเภอ · หน้าถัดไปตามหัวข้อที่เลือก (สรุป รายอำเภอ รายวัสดุ ปฏิทินเก็บเกี่ยว การขายจริง ผู้ลงทะเบียน ประวัติเจ้าหน้าที่) · แยกข้อมูลจริงกับประมาณการ ไม่มีชื่อ/เบอร์ในรายงาน
- Apps Script: ไฟล์ใหม่ `Admin.gs`, `Reports.gs` · ลบ `Sso.gs` · ชีตใหม่ `ggh_admins`, `ggh_admin_log` · `APP_VERSION` 4.0.0

## ใหม่ในรุ่น 3.1.0 (หน้าบันทึกข้อมูล · PIN · ขายแล้ว — 25 พ.ย. 2569)

- **หน้าบันทึกข้อมูล (เกษตรกร):** การ์ดแปลงแบ่งเป็นหมวดพร้อมไอคอน — พืชและวัสดุเหลือใช้ · ช่วงเวลา · ขนาดแปลง (ไร่/งาน/ตร.ว. มีหน่วยในช่อง) · ตำแหน่งแปลง — หัวการ์ดใช้รูปวัสดุแบบเดียวกับหน้าแรก และบอก "ต.… อ.… จ.…" ของหมุดทันทีที่ปัก/ลาก · ปุ่มใหญ่ บันทึก / ขายแล้ว / ลบ (ลบต้องยืนยัน)
- **วันที่เริ่มต้น:** วันปลูก = วันนี้ · วันเก็บเกี่ยว = วันปลูก + อายุพืช (ข้าว 120 · ข้าวโพด 110 · อ้อย 330 · มัน 300 · อื่นๆ 100 วัน) เปลี่ยนพืช/วันปลูกแล้วขยับตาม จนกว่าเกษตรกรแก้วันเก็บเกี่ยวเอง
- **เพิ่มพืช ข้าวโพดเลี้ยงสัตว์ → วัสดุ ซังข้าวโพด** (ผู้รับซื้อเลือกรับซังข้าวโพดได้)
- **หมุดบนแผนที่หลังเข้าสู่ระบบ = หน้าแรก:** แปลง = วงกลมเขียวรูปวัสดุ · จุดรับซื้อ = ป้ายรถบรรทุก · แปลงของฉันมีขอบน้ำเงิน · หมุดบนแผนที่ย่อในการ์ดแบบเดียวกัน
- **PIN 6 หลัก:** ลงทะเบียนต้องตั้ง PIN (ห้ามเลขเรียง/เลขซ้ำ) · เข้าสู่ระบบด้วยเบอร์ + PIN · ผู้ใช้เดิมตั้ง PIN ครั้งเดียวตอนเข้าสู่ระบบครั้งถัดไป · ผิด 5 ครั้งล็อก 15 นาที · เก็บเฉพาะ SHA-256 + salt ใน users!B · ลืม PIN: Super Admin ใน ABM ล้างได้ (`abm_pin_reset`)
- **ขายแล้ว:** บันทึกวันที่ขาย ปริมาณ (ตัน) จำนวนเงิน (บาท) ผู้ซื้อ (ไม่บังคับ) → แปลงออกจากตลาด แถวใหม่ในชีต `sales` · การ์ดแสดงสรุปการขาย + "ประกาศรอบการผลิตใหม่" · feed ไป ABM ส่งการขายของจังหวัด (ไม่มีเบอร์/ชื่อผู้ซื้อ)
- **ปิดการเข้าระบบผ่านตัวตนกลาง** (`ssoLoginServer`, `ssoProvisionServer` เลิกใช้ตั้งแต่ 2.9.3) เพื่อไม่ให้ข้าม PIN
- Apps Script: ไฟล์ใหม่ `Pin.gs` · `APP_VERSION` 3.1.0

## ใหม่ในรุ่น 3.0.0 (ใช้ได้ทุกจังหวัด — 25 พ.ย. 2569)

- **ชื่อตามจังหวัด:** "Green Gain Hub: จังหวัด…" บรรทัดที่ 2 "ศูนย์กลางเชื่อมโยงการซื้อ-ขายวัสดุเหลือใช้ทางการเกษตร" — ก่อนเข้าสู่ระบบเป็นจังหวัดที่เลือกบนหน้า (จำไว้ในเครื่อง) หลังเข้าสู่ระบบเป็นจังหวัดของผู้ใช้เอง · ตราจังหวัดแสดงเฉพาะกำแพงเพชร (จังหวัดอื่นยังไม่มีตรา) · ท้ายหน้า "สำนักงานเกษตรจังหวัด…"
- **ขอบเขต 77 จังหวัด 926 อำเภอ 7,517 ตำบล** จากชุดข้อมูล "1. ขอบเขตพื้นที่รายจังหวัด" (Thailand Agri-Risk Map Burning, QA 77/77) ย่อด้วย `tools/geo/build.py` → `frontend/geo/provinces.json` + `frontend/geo/p/<รหัส>.json` (รวม ~9 MB โหลดเฉพาะจังหวัดที่ดู) — สคริปต์แก้ชื่อเพี้ยน (เข้ารหัสผิด/สะกดผิด) รวมเกาะเป็นอำเภอเดียว และจัดตำบลที่รหัสอำเภอไม่ตรงตามตำแหน่ง
- **ลงทะเบียนต้องเลือกจังหวัด** (users J:K `Province_Code`, `Province`) · ทุกแปลง/จุดรับซื้อเก็บ จังหวัด–อำเภอ–ตำบล ที่เซิร์ฟเวอร์คำนวณจากหมุด (farmers S:X, buyers R:W) — หมุดนอกประเทศไทยบันทึกไม่ได้
- **ข้อมูลเดิม:** ครั้งแรกหลัง Deploy ระบบเติมจังหวัด–อำเภอ–ตำบลของทุกแปลง/จุดรับซื้อจากหมุดเอง (`geoMigrate_`, ครั้งเดียว) ผู้ใช้เดิมได้จังหวัดของหมุดแรกที่ตนปัก ผู้ที่ยังไม่เคยปักหมุดเป็นกำแพงเพชร
- **หน้าแรก:** หัวข้อ "สร้างรายได้จากฟางข้าว ใบอ้อย ซังข้าวโพด แทนการเผา" · การ์ดตัวเลข 3 ใบ = พื้นที่รวม (ไร่) · จำนวนเกษตรกรผู้ขาย (ราย, นับคนไม่นับแปลง + ผู้รับซื้อ) · ประมาณการชีวมวล (ตัน) · เอาการ์ด "ทุกวัสดุ" ออก (แตะการ์ดวัสดุซ้ำ หรือปุ่ม "ดูทุกวัสดุ") · ช่อง "เปลี่ยนจังหวัด" (จังหวัดที่มีประกาศอยู่บนสุดพร้อมจำนวน) · ตารางสรุปรายอำเภอของจังหวัดที่เลือก: พื้นที่รวม · จำนวนราย · ชีวมวล · ผู้รับซื้อ + แถวรวม

### ความเป็นส่วนตัวของแผนที่

- เกษตรกรได้รับข้อมูลผู้รับซื้อและแปลงของตนเองเท่านั้น
- เกษตรกรไม่ได้รับข้อมูลแปลงของเกษตรกรรายอื่น
- ผู้รับซื้อได้รับเฉพาะข้อมูลแปลงเกษตรกร ไม่ได้รับข้อมูลผู้รับซื้อรายอื่น
- การรวมแปลงของบัญชีใช้ `Owner_Telephone` และใช้ `Phone` เป็นคีย์สำรองสำหรับข้อมูลเก่า
