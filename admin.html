    กรอกเมื่อมีการชั่งหรือสำรวจจริง ระบบจะคำนวณ GHG ด้วยค่านี้แทนค่ามาตรฐาน (Custom Mode)

    ขายให้ผู้รับซื้อ / ปริมาณที่นำออกจริง (ไม่บังคับ)

    ใช้เชื่อมรายการนี้กับตลาดเศษวัสดุ ถ้ากรอกปริมาณที่ขายหรือนำออกจริง ระบบจะใช้คิดมูลค่าแทนค่าประมาณ (ก๊าซเรือนกระจกคิดเท่าเดิม)

    ผู้บันทึกข้อมูล:

    รายการบันทึก

    ราคาและค่าคำนวณก๊าซเรือนกระจก

    ราคากลางเศษวัสดุ

    ตั้งครั้งเดียว ใช้กับทุกชนิดพืชที่เลือก "ใช้ราคากลาง" มูลค่าทุกรายการและหน้าแรกเปลี่ยนตามทันที พืชที่ต้องการราคาเฉพาะ แก้ได้ในตารางค่าตามชนิดพืชด้านล่าง

    ค่าคำนวณก๊าซเรือนกระจก

    สูตรตาม IPCC 2006 Equation 2.27 ค่าคงที่แก้ไขได้ ทุกครั้งที่แก้จะเป็นชุดค่าใหม่ บันทึกในประวัติการใช้งาน และผลคำนวณทั้งหมดใช้ชุดค่าเดียวกันเสมอ (ไม่ผสมค่า AR5 กับ AR6)

    ค่าคงที่

    โหมดคำนวณเริ่มต้น (รายการที่ไม่ได้กรอกชีวมวลจริง)

    ราคา

    ขอบเขตการคำนวณ

      เป้าหมายและวิธีจัดการ

      เป้าหมายพื้นที่จัดการเศษวัสดุ (ไร่)

      เป้ารวมของอำเภอใช้คำนวณร้อยละ เป้ารายประเภทไม่บังคับ จำนวน นวส. ใช้คำนวณเป้าหมายต่อคนในรายงานราย Admin

      ประเภทการจัดการเศษวัสดุ

      ประเภทใช้กับพืชต้องระบุรายละเอียดนับมูลค่าลำดับสถานะจัดการ

      เพิ่มหรือแก้ไขประเภท

      ชื่อจังหวัดและหน่วยงาน

      นำเข้าข้อมูลเพาะปลูก

      ใช้รายงานจากระบบฐานข้อมูลทะเบียนเกษตรกรกลาง แยกตามเดือนที่คาดว่าจะเก็บเกี่ยว พืช 1 ชนิดต่อ 1 ไฟล์ นำเข้าพืชและปีการผลิตเดิมซ้ำ ระบบจะแทนที่ข้อมูลชุดเดิมให้

      1. เลือกชนิดพืช

      2. เลือกไฟล์ Excel

      3. ตรวจสอบข้อมูล

      4. ยืนยันนำเข้า

      ข้อมูลที่นำเข้าแล้ว

      หน้าแรกแสดงเฉพาะชุดที่สถานะ "ใช้งาน" ชุดที่ถูกแทนที่หรือลบจะเก็บไว้เป็นประวัติ

      พืชปีการผลิตไร่ช่วงเดือนสถานะนำเข้าเมื่อโดยจัดการ

      ชนิดพืช

      ชนิดพืชที่เปิดใช้งานจะให้เลือกตอนนำเข้า ชนิดเศษวัสดุใช้คำนวณปริมาณ (ถ้ามี BioRate ในชีต Research_Refs)

      พืชเศษวัสดุลำดับสถานะจัดการ

      เพิ่มหรือแก้ไขชนิดพืช

      รายงาน

      เลือกแบบรายงาน กดสร้างรายงาน แล้วพิมพ์ บันทึกเป็น PDF หรือดาวน์โหลด Excel/CSV ทุกครั้งที่ดูหรือส่งออกจะบันทึกในประวัติการใช้งาน

      แบบรายงาน
      ปรับแต่งส่วนของรายงาน

      การเชื่อมต่อระบบอื่น (API)

      KPP Smart Agri-Materials (รายงานอำเภอ)

      API สาธารณะของ Green Gain Hub

        เจ้าหน้าที่และผู้ดูแล

        เจ้าหน้าที่ลงทะเบียนเองได้ที่หน้าเข้าสู่ระบบ (เข้าใช้ด้วยหมายเลขโทรศัพท์ และได้สิทธิ์ Admin เสมอ) ถ้าพบบัญชีที่ไม่ถูกต้อง ให้แก้ไขสถานะเป็น "ระงับ" ได้ทันที

        Super Admin จัดการได้ทุกส่วน Mini Super Admin จัดการได้เทียบเท่า Super Admin แต่จัดการบัญชี Super Admin ไม่ได้ Admin (ผู้บันทึกข้อมูล) บันทึกและเห็นข้อมูลเฉพาะอำเภอที่ลงทะเบียน

        ชื่อชื่อผู้ใช้โทรศัพท์บทบาทหน่วยงานสถานะเข้าใช้ล่าสุดจัดการ
